📋 Documentation API IA

Le service d'IA est accessible via le proxy inverse (même origine) :

/ai/forecast?product_id=<id>

Endpoints disponibles :

  • • GET /ai/health — état du service
  • • GET /ai/forecast?product_id=X — prévision avec confiance et statut
  • • POST /ai/etl/run — extraction des historiques de vente
  • • GET /ai/production-recommendations, /ai/anomalies, /ai/segmentation, /ai/insights — futurs (501)

L'URL réelle du service IA est masquée derrière le proxy ; elle n'est jamais exposée au frontend.
